# Personal Portfolio Website

Simple static portfolio site to showcase your work and make it easy for employers to contact you.

## Run locally

1. Open `/Users/stevenle/vz/personal/index.html` in your browser.
2. Or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize before publishing

- Update contact email in `index.html` (`hello@yourname.com`).
- Replace LinkedIn/GitHub/profile URLs in `index.html`.
- Replace project cards with your actual projects and links.
- Update SEO/metadata and JSON-LD values in the `<head>` and footer.

## Files

- `index.html` - Content and page structure
- `styles.css` - Visual design and responsive layout
- `script.js` - Mobile menu, reveal animations, and dynamic year
